# Партнёрский кабинет MakeBiz

Личный кабинет партнёра (сделки, комиссии, аналитика, реф-ссылка, лиды, обучение, выводы) и админка команды для заведения партнёров.

- **Прод:** `partners.makebiztehnologies.com` (сейчас Vercel, переезд на Timeweb Apps: `docs/deploy-timeweb.md`)
- **Пайплайн:** пуш в `main` → хостинг пересобирает сам
- **Стек:** Next.js (App Router), Postgres, Node-воркер
- **Дизайн:** система MakeBiz (Oxygen, `#03235F` / `#013CA4` / `#074EE8`)

## Как устроено

```
Браузер → Next.js (web) ─→ Postgres ←─ воркер ─→ gateway (agw.makebiztehnologies.com) → Bitrix (основной / Бирюза)
                  │                        └──→ Telegram (личный аккаунт Антона + бот), почта
                  └─→ gateway (чтение сделок)
```

**Кабинет не ходит в Bitrix напрямую**, только через gateway. В каждый портал пишет один исполнитель: основной CRM Диспетчер, Бирюзу Бирюза.

Кабинет хозяин карточки партнёра: ассистентка заводит партнёра в `/admin`, дальше фоновая очередь (`jobs`) сама создаёт контакт и сделку «Сопровождение» в выбранном Битриксе, Telegram-группу и письмо-приглашение. Упавшие шаги повторяются автоматически и кнопкой «Повторить».

| Правда о… | Где |
|---|---|
| Клиенты, сделки, суммы, факт оплаты | **Bitrix** |
| Партнёры, дерево приглашений, входы, леджер начислений, лиды из кабинета, обучение | **Postgres кабинета** |

## Вознаграждение

Услуги (внедрение, разработка, агенты): **20% с первой оплаты каждого приведённого клиента**, затем **10% с его оплат в течение 12 месяцев**.

Приложения (Solara и др.): **30% с каждой оплаты весь срок жизни клиента**, начисляется автоматически по вебхуку ЮKassa.

Второй уровень: пригласивший получает **10% от вознаграждения** приглашённого. Выплата: физлицу на карту за вычетом 20%, самозанятому, ИП и юрлицу полностью. Ставки лежат в таблице `settings`.

## Входы и роли

`/login` один для всех. Команда (`admin_users`, роли `admin`, `assistant`) попадает в `/admin`, партнёр в кабинет. Партнёр задаёт пароль по ссылке-приглашению `/invite/<токен>` (7 дней). Пароли scrypt, сессия в httpOnly-куке, в базе только хэш токена.

## Структура

```
app/            экраны кабинета, /admin, /login, /invite, API-роуты
lib/
  auth.js         пароли, сессии, роли
  partners.js     заведение партнёра, дубли, реф-коды, сводка
  jobs.js         очередь фоновых задач
  commissions.js  расчёт начислений
  gateway.js      клиент gateway
  sync.js         gateway → база
worker/         воркер очереди: bitrix.mjs, telegram.mjs, mailer.mjs, bootstrap.mjs
db/
  migrations/     схема (0001…0005)
  migrate.mjs     раннер миграций
  create_admin.mjs  пользователь команды из терминала
docs/           запуск на Timeweb
```

## Команды

```bash
npm install
npm run dev              # локально
npm test                 # юнит-тесты
npm run migrate          # применить миграции
npm run worker           # воркер очереди
npm run worker:start     # миграции + воркер (для хостинга)
npm run admin:create -- --login anton --name "Антон" --role admin --telegram ник
npm run tg:login         # разово: строка сессии Telegram (только в секреты сервера!)
```

## Переменные окружения

Полный список с пояснениями: `docs/deploy-timeweb.md`. Основные: `DATABASE_URL`, `DIRECT_URL`, `DB_CA_CERT`, `APP_URL`, `GATEWAY_URL`, `GATEWAY_KEY`, `APP_WEBHOOK_SECRET`; для воркера ещё `TG_*`, `SMTP_URL`, `MAIL_FROM`, `ADMIN_BOOTSTRAP_*`.

## Состояние

Готово: экраны кабинета, админка с заведением партнёров, входы по паролю, очередь с воркером (Битрикс через gateway, Telegram-группа, письмо), трек приложений 30%, схема базы с миграциями, тесты.

Ждёт gateway: `POST /partner` и поля привязки клиента к партнёру (задание Диспетчеру и Бирюзе). Экраны партнёра пока на демо-данных, переключение на живые данные после ручек gateway.
