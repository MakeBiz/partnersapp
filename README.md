# Партнёрский кабинет MakeBiz

Личный кабинет партнёра: сделки, комиссии, аналитика, реф-ссылка, лиды, обучение, выводы.

- **Прод:** `partners.makebiztehnologies.com`
- **Пайплайн:** GitHub → Vercel (проект `partners_app`), пуш в `main` деплоится сам
- **Стек:** Next.js (App Router), Postgres
- **Дизайн:** система MakeBiz (Oxygen, `#03235F` / `#013CA4` / `#074EE8`)

## Как устроено

```
Браузер → Next.js на Vercel → gateway (agw.makebiztehnologies.com) → Bitrix
                            ↘ Postgres (партнёрская механика)
```

**Кабинет не ходит в Bitrix напрямую** — только через партнёрские ручки gateway, которые читают Bitrix вебхуком Диспетчера.

Разделение данных:

| Правда о… | Где |
|---|---|
| Клиенты, сделки, суммы, факт оплаты, карточка партнёра | **Bitrix** |
| Дерево приглашений, леджер начислений, лиды из кабинета, обучение, баллы, аккаунты | **Postgres кабинета** |

## Вознаграждение

**20% — welcome-бонус: один раз, с первого приведённого клиента. Дальше всегда 10%.**

Второй уровень: пригласивший получает **10% от комиссии** приглашённого (не от суммы сделки). Третий уровень заложен настройкой и выключен.

Выплата: на карту физлицу — за вычетом 20%; на ИП или юрлицо — полностью.

Ставки и правила лежат в таблице `settings`, а не в коде.

## Структура

```
app/            экраны кабинета и API-роуты
lib/
  commissions.js  расчёт начислений (welcome, уровни, отмены) + тесты
  gateway.js      клиент партнёрского API + тесты
  sync.js         gateway → база: партнёр, дерево, леджер
  db.js           пул соединений
db/
  migrations/     схема
  migrate.mjs     раннер миграций
  seed_demo.mjs   демо-данные
  demo/           демо-набор
```

## Команды

```bash
npm install
npm run dev              # локально
npm test                 # тесты расчёта и клиента gateway
npm run migrate          # применить миграции
npm run migrate:status   # что применено
node db/seed_demo.mjs    # демо-данные (не для боевой базы!)
```

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | база, transaction-пул |
| `DIRECT_URL` | миграции, session-пул |
| `GATEWAY_URL` | `https://agw.makebiztehnologies.com` |
| `GATEWAY_KEY` | ключ коллеги, только на сервере |
| `DB_CA_CERT` | *(опц.)* CA для полной проверки TLS |

## Состояние

Готово: экраны кабинета, схема базы с миграциями, расчёт начислений, клиент gateway, синхронизация, демо-данные. Всё покрыто тестами (31 юнит + интеграционные на настоящем Postgres).

На моках пока: `app/api/*` отдаёт данные из `lib/mock.js`. Переключение на живые данные — после того, как gateway добавит `createdAt` у сделок и `uplineContactId`, `payRatio` в профиле (см. «Диспетчеру - дополнение к ред. 2»).

Без дат сделок welcome-бонус **не назначается** — недоначислить и потом добавить безопаснее, чем переплатить и забирать назад.
