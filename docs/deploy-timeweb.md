# Партнёрский кабинет на Timeweb: запуск по шагам

Обновлено 22.09.2026. Код: github.com/MakeBiz/partnersapp, ветка `main`. Пока идёт настройка, текущий сайт работает на Vercel, домен переключаем в самом конце

## Что понадобится в Timeweb Cloud

Нужны две вещи, отдельный сервер (VPS) не нужен:

1. **База данных PostgreSQL** (управляемая, раздел «Базы данных»). В ней лежат партнёры, логины и пароли, приглашения, очередь задач, дерево «кто кого пригласил», начисления и оплаты приложений
2. **Одно приложение** (раздел «Apps»). Это сам кабинет: сайт, админка и фоновый воркер, который заводит партнёров в Битрикс, создаёт Telegram-группы и отправляет письма

Сделки, клиенты и суммы оплат по-прежнему живут в Битриксе, кабинет их читает через gateway. В базе только то, чего в Битриксе нет или что нельзя хранить там безопасно

## Шаг 1. База данных

1. Timeweb Cloud → «Базы данных» → «Создать» → PostgreSQL (версия 15 или 16), минимальная конфигурация, регион тот же, где будет приложение
2. Имя базы: `partners`. Пользователь и пароль пусть сгенерирует Timeweb. Если задаёшь пароль сам, используй только латинские буквы и цифры: символы вроде `@ : / ? #` ломают строку подключения
3. Включить публичный доступ к базе (приложению нужно к ней подключаться)
4. Собрать строку подключения по данным из карточки базы:

```
postgres://ПОЛЬЗОВАТЕЛЬ:ПАРОЛЬ@АДРЕС:5432/partners
```

Эту строку никуда не отправляй, она нужна только в шаге 2

Таблицы создавать не нужно: приложение само создаёт их при первом запуске

## Шаг 2. Приложение

1. Timeweb Cloud → «Apps» → «Создать» → **Backend** → **Node.js**, версия 20 или новее
2. Репозиторий: GitHub → `MakeBiz/partnersapp`, ветка `main`, автодеплой при пуше включить
3. Команда сборки: `npm ci && npm run build`
4. Команда запуска: `npm run start:all`
5. Переменные окружения (вводятся только здесь, в панели Timeweb):

| Переменная | Что вписать |
|---|---|
| `DATABASE_URL` | строка из шага 1 |
| `APP_URL` | адрес приложения, который выдал Timeweb (`https://…`). После переключения домена поменяем на `https://partners.makebiztehnologies.com` |
| `ADMIN_BOOTSTRAP_LOGIN` | твой логин для входа, например `anton` |
| `ADMIN_BOOTSTRAP_PASSWORD` | твой пароль для первого входа (от 8 символов) |
| `ADMIN_BOOTSTRAP_TELEGRAM` | твой ник в Telegram без @ |

6. Запустить деплой. В логах приложения должны появиться строки:
   - `Применено миграций: 5`
   - `bootstrap admin: {"created":"anton","role":"admin"}`
   - `Ready`

Если в логах `The server does not support SSL connections`, добавь переменную `DB_SSL` со значением `off` и перезапусти

## Шаг 3. Первый вход

1. Открыть `<адрес приложения>/login`, войти логином и паролем из шага 2. Откроется админка `/admin`
2. Удалить переменную `ADMIN_BOOTSTRAP_PASSWORD` (вход уже работает, пароль хранится в базе в зашифрованном виде)
3. Завести ассистентку: снова задать `ADMIN_BOOTSTRAP_LOGIN` (её логин), `ADMIN_BOOTSTRAP_PASSWORD` (её пароль), `ADMIN_BOOTSTRAP_TELEGRAM` (её ник), добавить `ADMIN_BOOTSTRAP_ROLE` = `assistant`, перезапустить приложение, затем снова удалить пароль. Твою учётку это не затрагивает

## Шаг 4. Проверка

В админке нажать «Новый партнёр», завести тестового. Что будет:

- партнёр появится в списке, ссылку-приглашение можно скопировать
- шаги «CRM», «Чат», «Письмо» будут красными с пояснением «не настроено». Так и должно быть, пока не подключены gateway, Telegram и почта
- открыть ссылку-приглашение в другом браузере, задать пароль, войти как партнёр

Когда шаги подключатся, кнопка «Повторить» в карточке партнёра догонит всё, что было пропущено

## Потом, по мере готовности

| Что | Переменные | Когда |
|---|---|---|
| Битрикс через gateway | `GATEWAY_URL` = `https://agw.makebiztehnologies.com`, `GATEWAY_KEY` = ключ от Диспетчера | когда Диспетчер сделает `POST /partner` |
| Оплаты приложений (ЮKassa) | `APP_WEBHOOK_SECRET` | при подключении Solara |
| Telegram-группы от твоего аккаунта | `TG_API_ID`, `TG_API_HASH`, `TG_SESSION`, `TG_BOT_USERNAME`, `TG_BOT_TOKEN`, `TG_TEAM_USERNAMES` | шаг 4 плана, подготовлю вход в Telegram двойным кликом |
| Письма с приглашением | `SMTP_URL`, `MAIL_FROM` | когда будет почтовый ящик для рассылки |

## Шаг 5. Домен (в самом конце)

Когда всё работает: в настройках приложения Timeweb добавить домен `partners.makebiztehnologies.com`, у регистратора домена поменять DNS-запись на ту, что покажет Timeweb, в переменной `APP_URL` указать `https://partners.makebiztehnologies.com`. Проект на Vercel не удалять ещё неделю, на случай отката
